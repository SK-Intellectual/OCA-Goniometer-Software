# OCA-Goniometer-Software
# Optical Contact Angle Analysis

A computational framework for **static and dynamic contact angle measurement** from droplet images, developed as part of the project **“Development of a Cost-Effective Optical Contact Angle Goniometer.”**

The software processes droplet images to extract the liquid–solid interface and accurately determine contact angles across a wide range of wetting conditions. The framework is designed to work with both conventional static droplets and dynamically evolving droplets, enabling its use in experiments where contact angle hysteresis may subsequently be evaluated.

> **Note:** Contact angle hysteresis computation is **not implemented** in the current version. The dynamic contact-angle measurements generated by this software can, however, serve as inputs for hysteresis analysis.

---

## Features

* **Static Contact Angle Measurement**

  * Automated extraction of the droplet profile from an image.
  * Identification of the solid–liquid–air contact points.
  * Calculation of left and right contact angles.
  * Suitable for droplets ranging from highly hydrophilic to highly hydrophobic surfaces.

* **Dynamic Contact Angle Measurement**

  * Frame-by-frame analysis of evolving droplets.
  * Tracking of contact-angle variation during droplet motion or volume change.
  * Enables extraction of advancing and receding contact-angle data.
  * Provides the measurements required for subsequent contact-angle hysteresis analysis.

* **Robust Droplet Profile Extraction**

  * Image-processing pipeline designed to handle variations in droplet shape, contrast, and wetting regime.
  * Computational methods for extracting the droplet boundary and reconstructing the local interface near the contact line.

* **Asymmetric Droplet Handling**

  * Independent estimation of left and right contact angles.
  * Avoids relying solely on the assumption of perfect droplet symmetry.

* **Real-Time Processing**

  * Optimized image-processing pipeline capable of processing individual frames with **<50 ms latency** under the developed setup.

## Methodology

The overall analysis pipeline can be summarized as:

```text
Input Image / Video
        │
        ▼
Image Pre-processing
        │
        ▼
Droplet Detection
        │
        ▼
Droplet Profile Extraction
        │
        ▼
Interface / Contact-Line Identification
        │
        ▼
Geometric Reconstruction
        │
        ▼
Contact Angle Calculation
        │
        ├──────────────► Static Contact Angle
        │
        └──────────────► Dynamic Contact Angle
```

### 1. Image Acquisition

The software accepts droplet images or frames acquired using an optical imaging setup. For dynamic measurements, consecutive frames can be processed to obtain the temporal evolution of the contact angle.

### 2. Droplet Profile Extraction

The droplet boundary is extracted from the acquired image using image-processing techniques. The extracted profile forms the basis for determining the liquid–air interface and locating the contact line.

A key challenge in contact-angle measurement is that the apparent droplet boundary can vary significantly with:

* Surface wettability
* Droplet geometry
* Image contrast
* Illumination
* Contact-line location
* Degree of droplet asymmetry

The implemented processing approach is therefore designed to obtain a stable droplet profile before calculating the local interface geometry.

### 3. Contact-Line Identification

The contact points between the droplet and the solid surface are identified from the extracted profile.

For asymmetric droplets, the left and right contact lines are treated independently, allowing separate contact angles to be calculated.

### 4. Contact Angle Calculation

The contact angle is obtained from the local geometry of the liquid–air interface near the contact line.

The framework supports measurement over a broad range of wetting conditions, from strongly hydrophilic to highly hydrophobic surfaces.

### 5. Dynamic Analysis

For dynamic experiments, the same analysis is performed across successive frames:

```text
Frame 1 → θ₁
Frame 2 → θ₂
Frame 3 → θ₃
   ⋮
Frame n → θₙ
```

This produces a time-dependent contact-angle profile that can be used to study droplet motion and determine advancing/receding contact-angle behavior.

The resulting measurements can subsequently be used for calculating:

[
\Delta\theta = \theta_A - \theta_R
]

where:

* ( \theta_A ) = advancing contact angle
* ( \theta_R ) = receding contact angle

**The calculation of contact-angle hysteresis itself is not implemented in this repository.**

## Performance

The developed computational pipeline was evaluated across a wide range of wetting conditions.

| Parameter                  |            Performance |
| -------------------------- | ---------------------: |
| Contact-angle range tested |           **10°–175°** |
| Measurement error          |               **< 1°** |
| Image-processing latency   |            **< 50 ms** |
| Measurement type           |       Static & Dynamic |
| Droplet geometry           | Symmetric & Asymmetric |

The results demonstrate the ability of the developed methodology to maintain accurate contact-angle estimation across both hydrophilic and superhydrophobic regimes.

## Project Context

This software was developed as part of a **cost-effective optical contact angle goniometer** designed to provide an accessible alternative to commercially available systems.

The complete experimental setup was developed around a low-cost optical configuration, with the prototype hardware costing approximately **₹25,000**.

The system combines:

* Optical droplet imaging
* Automated image processing
* Computational contact-angle estimation
* A custom experimental setup for controlled droplet analysis

The software component was developed to reduce the dependence on manual contact-angle measurements and provide a reproducible computational workflow.

## Limitations

The current version focuses specifically on **static and dynamic contact-angle calculation**.

The following functionality is **not currently implemented**:

* Automatic contact-angle hysteresis calculation
* Complete automated experimental control
* Automated classification of advancing vs. receding states
* Surface-energy calculation

Dynamic contact-angle measurements generated by the software can nevertheless be exported or used as the basis for implementing these analyses in future versions.
